**1.** A tabela "Cliente" já foi criada no banco de dados, com sua estrutura definida. Agora é preciso inserir um novo registro de cliente, com nome e telefone, dentro dessa tabela. Qual comando SQL, e de qual categoria da linguagem, resolve essa tarefa?

- [ ] a) `CREATE TABLE`, comando de DDL usado para inserir registros em uma tabela
- [ ] b) `INSERT INTO`, comando de DML (Data Manipulation Language) usado para inserir um novo registro em uma tabela existente
- [ ] c) `DROP TABLE`, comando usado para inserir dados na tabela
- [ ] d) A linguagem DML não é usada para inserir dados, apenas para consultá-los
- [ ] e) `ALTER TABLE`, comando usado para alterar os dados já existentes na tabela

**2.** Antes de criar qualquer banco ou tabela, uma equipe precisa instalar um Sistema Gerenciador de Banco de Dados (SGBD) em um servidor, definindo a porta de escuta, o usuário administrador e as regras de acesso remoto. A qual etapa do projeto de banco de dados isso corresponde?

- [ ] a) Instalação e configuração do SGBD, etapa anterior à criação de bancos e tabelas, que prepara o serviço para aceitar conexões
- [ ] b) DML, pois toda instalação de SGBD é feita com comandos `INSERT`
- [ ] c) DDL, pois instalar um SGBD é o mesmo que criar uma tabela
- [ ] d) Modelo conceitual, pois a instalação do SGBD é sempre a primeira etapa do projeto de dados
- [ ] e) Não é necessário configurar nada depois de instalar um SGBD
